🖨️ MeraPrint Host

Apne PC ko Host banayein — phone / doosre PC se kahin se bhi print, scan, file aur remote. Built by Pankaj Jaiswal.
⬇️ MeraPrint Host Install download karo
  1. Download hui MeraPrint-Host-Install.bat chalaiye. (Browser bole "khatarnak ho sakti hai" to Keep / Rakhein, Windows bole to More info → Run anyway.)
  2. Node.js na ho to wo khud lagega (ek baar).
  3. Host chalu hoga aur browser me Admin panel khulega — wahan aapka apna Host ID aur PIN dikhega.
  4. Windows Firewall poochhe to Private networks → Allow.
  5. Phone (MeraPrint app) ya doosre PC ke browser me Host ID + PIN daal kar jodiye.

Aapko pata hona chahiye

  • Har Host ka apna Host ID, PIN, jude device aur share folder — kisi aur ko aapka data nahi dikhta.
  • Kaun print / scan / remote / file kar sake — aap apne Admin panel (http://localhost:8791) me chunte hain.
  • Naye update apne aap aate hain (digital signature jaanch kar).
  • Install folder: C:\MeraPrint-Host
